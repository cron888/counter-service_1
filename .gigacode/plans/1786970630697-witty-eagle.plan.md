# План реализации: NoSuchProductException, ShopError, ShopControllerAdvice

## Задачи

### 1. Создать `NoSuchProductException`
- **Файл**: `src/main/java/org/skypro/counter/exception/NoSuchProductException.java`
- Наследуется от `RuntimeException`
- Конструктор с сообщением (и необязательной причиной)

### 2. Создать `StorageService` с методом `getProductById`
- **Файл**: `src/main/java/org/skypro/counter/service/StorageService.java`
- Метод `getProductById(long id)` — возвращает заглушку (например, название товара по ID)
- При отсутствии товара — выкидывает `NoSuchProductException` (вместо `IllegalArgumentException`)
- Для тестирования: простой `Map<Long, String>` с несколькими товарами

### 3. Создать немодифицируемый `ShopError`
- **Файл**: `src/main/java/org/skypro/counter/dto/ShopError.java`
- Два `final String` поля: `code` и `message`
- Конструктор, геттеры (без сеттеров — немодифицируемый)
- Аннотации `@JsonPropertyOrder({"code", "message"})` для порядка JSON-полей

### 4. Создать `ShopControllerAdvice`
- **Файл**: `src/main/java/org/skypro/counter/controller/ShopControllerAdvice.java`
- `@RestControllerAdvice`
- `@ExceptionHandler(NoSuchProductException.class)` метод, возвращающий `ResponseEntity<ShopError>`
- HTTP 404 (NOT_FOUND)
- Код ошибки: `"PRODUCT_NOT_FOUND"`, сообщение: `"Product not found"`
